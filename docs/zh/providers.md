# 翻译服务

DualSub 使用你在设置页 **翻译** 部分选择的服务翻译字幕。

| 服务             | 需要什么                                                                      |
| ---------------- | ----------------------------------------------------------------------------- |
| 微软翻译（默认） | 无需任何设置                                                                  |
| 谷歌翻译         | 无需任何设置                                                                  |
| DeepL            | DeepL API 密钥，免费或专业套餐均可                                            |
| AI 翻译          | OpenAI 兼容服务的 API 密钥、地址和模型                                        |
| Google Vertex AI | Google Cloud 项目、区域和模型，以及访问令牌（手动粘贴，或由服务账号文件生成） |

微软翻译和谷歌翻译使用未公开的端点，可能随时变化。如果需要有文档保障的服务契约，请使用需要密钥的服务。

DualSub 逐行翻译字幕，不参考前后几行。节目有你的语言的自带翻译时，DualSub 会改用它；关闭“语言”部分的 **使用节目自带的翻译** 即可停用。

## 服务出问题时

你选的服务持续失败时（密钥被拒、额度用完，或请求被拒绝），会先由微软翻译、再由谷歌翻译接替，字幕不会中断。十分钟后，或你修改它的设置后，DualSub 会重新尝试你的服务。暂时性故障只由备用服务处理当次请求。

如果希望字幕文字只发送给你选的服务，请关闭 **这个服务出问题时继续翻译**。

## 请求间隔

每个服务的请求之间都有最短间隔，有些还会限制一段时间内发送的量：

- 微软翻译：每分钟的字符数
- 谷歌翻译：每几秒的字节数
- DeepL：只有间隔；额度以 DeepL 的响应为准
- AI 翻译和 Google Vertex AI：每分钟的请求数

这些限制保存在扩展的后台工作进程中，工作进程重启后重新计算，并不代表你账户的额度。打开高级选项后，**翻译请求之间的间隔** 可以为所有服务加长间隔。

## 常见问题

- **翻译停止，或由其他服务提供**：“翻译”部分和弹出窗口会显示出问题的服务、问题所在，以及正在接替的服务。请检查它的密钥、套餐或地址，或改选其他服务。
- **服务提示请求太多**：调大 **翻译请求之间的间隔**。
