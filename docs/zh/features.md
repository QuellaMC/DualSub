# 功能特性

## 核心功能

- 双语字幕显示：同时显示原文和翻译
- 多平台支持：适配 Netflix 与 Disney+
- 多翻译服务商：Google、Microsoft、DeepL、OpenAI 兼容、Vertex AI Gemini
- 稳健翻译：服务商速率限制、重试与缓存

## 自定义选项

- 灵活布局：上下或左右排列
- 外观控制：字体大小、间距、显示顺序，以及可跟随平台原生外观或使用你自己外观的字幕样式，在按视频实际比例显示的画面上编辑
- 垂直定位：精确控制字幕位置
- 平台定位：平台为避开画面文字而上移的字幕，以及同时显示的多条字幕，都按平台的位置绘制
- 时间偏移：微调字幕同步，并用人声与字幕的时间线对照
- 按网站设置：每个网站可以单独设置开关、语言、外观与时间
- 简明的设置页：所有设置集中在一页，支持搜索、撤销，并显示你的字幕示例
- 多语言界面：支持 EN、ES、JA、KO、ZH-CN、ZH-TW

## 高级功能

- 查词：点一下字幕里的单词，就能看到它的翻译和词典释义，无需设置；“用 AI 解释”还会说明它在这一行里的用法、背后的文化与历史，通过你自己的 OpenAI 或 Google Gemini 密钥
- 性能调优：可配置字幕翻译请求之间的延迟
- 高级选项：精确数值、各项限制、备份与恢复，以及诊断报告，按需显示
- 日志系统：可配置日志级别
- 官方字幕集成：节目有自带的翻译时优先使用，它的每一行都与对应的原文字幕一起显示
