# 功能特性

## 核心功能

- 双语字幕显示：同时显示原文和翻译
- 多平台支持：适配 Netflix 与 Disney+
- 多翻译服务商：Google、Microsoft、DeepL、OpenAI 兼容、Vertex AI Gemini
- 稳健翻译：服务商速率限制、重试与缓存

## 自定义选项

- 灵活布局：上下或左右排列
- 外观控制：字体大小、间距、显示顺序，以及可跟随平台原生外观或自定义外观的字幕样式，可在设置页预览
- 垂直定位：精确控制字幕位置
- 平台定位：平台为避开画面文字而上移的字幕，以及同时显示的多条字幕，都按平台的位置绘制
- 时间偏移：微调字幕同步
- 按网站设置：每个网站可以单独设置开关、语言、外观与时间
- 简明的设置页：所有设置集中在一页，支持搜索、撤销与实时预览
- 多语言界面：支持 EN、ES、JA、KO、ZH-CN、ZH-TW

## 高级功能

- 单词解释：对你点击的单词给出文化、历史、语言解读（OpenAI 或 Google Gemini）
- 性能调优：可配置字幕翻译请求之间的延迟
- 高级选项：精确数值、各项限制、备份与恢复，以及诊断报告，按需显示
- 日志系统：可配置日志级别
- 官方字幕集成：优先使用平台原生字幕（Netflix）

参见：`docs/zh/platforms.md` 与 `docs/zh/providers.md`。
