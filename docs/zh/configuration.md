# 设置

DualSub 安装后即可在 Netflix 和 Disney+ 上使用，无需任何设置。本页介绍弹出窗口、设置页、按网站设置，以及 DualSub 如何保存你的密钥。

## 弹出窗口

点击 Chrome 工具栏上的 DualSub 按钮会打开弹出窗口。在 DualSub 支持的网站上，它就像一个遥控器：

- DualSub 是否正在为这个视频工作，以及只对该网站打开或关闭 DualSub 的开关。
- **我的语言**：字幕翻译成的语言，默认是浏览器的语言。
- **原文字幕**：原文字幕显示的语言。默认为 **自动**，跟随视频中所说的语言，在播放器里切换音轨时也会跟随。也可以在设置页的“语言”部分固定为某一种语言。视频本身就是你的语言时只显示一行。
- 文字大小、时间和位置，逐步调整，视频即时跟随。
- 你的翻译服务出问题时会显示提示，并可前往其设置。

在其他网页上，弹出窗口会介绍 DualSub，并可打开它支持的网站。

## 设置页

设置页包含所有设置，弹出窗口中的设置也在其中。每项更改都会立即保存；确认更改的提示中可以撤销，在文本框之外按 Ctrl+Z（⌘Z）也可以撤销。搜索框可以用日常用语查找设置，例如“两遍”“大小”或“颜色”。

- **开始**：DualSub 在哪些网站上工作、你的字幕示例，以及你的语言、文字大小和翻译服务。
- **语言**：你的语言、原文字幕显示什么，以及节目自带的翻译，并在韩剧或英语电影上显示示例。节目自带的翻译的每一行，都与对应的原文字幕一起出现、一起消失。
- **样式**：按视频的比例在画面上显示字幕，可切换夜晚或白天。点一行即可改它的样式，拖动字幕即可移动，也可以打开 **全屏** 按实际大小查看。画面旁的面板包含大小、位置、外观、译文颜色和两行（哪一行在上、上下或并排，以及间距）。
- **时间**：人声与字幕的时间线。以半秒为单位提前或推迟显示字幕。
- **翻译**：[翻译服务](providers.md)及其设置，以及你选的服务出问题时是否由免费服务接替。
- **释义**：[查词与用 AI 解释](ai-context.md)。
- **网站**：在每个网站上打开或关闭 DualSub，以及隐藏各网站自带的字幕。
- **帮助**：一键解决常见问题，例如字幕显示两遍，或节目自带的翻译配错了原文字幕。

在“样式”部分的 **外观** 一行中，**和网站一样** 按你的 Netflix 或 Disney+ 账户的字幕外观设置绘制字幕。现成外观（带底色、经典、高对比度和影院）是你自己外观的起点，之后可以修改字体、边缘、颜色和底色。**译文颜色** 适用于所有外观。文字大小是外观基准大小的缩放倍数，基准随视频高度变化。

### 高级选项

打开顶部栏的 **高级选项** 开关后，还会显示：

- 精确的时间偏移
- **与原文字幕同步显示**：让节目自带的翻译与对应的原文字幕同步显示
- **翻译请求之间的间隔**
- 按网站设置
- AI 服务的地址、模型和限制
- Disney+ 上 **要跳过的字幕轨**
- **高级** 部分：备份与恢复、JSON 格式的设置、**浏览器控制台显示的详细程度**、诊断报告，以及保留密钥及其配套地址、套餐和模型的重置

## 按网站设置

Netflix 和 Disney+ 可以各自保留以下设置：是否开启 DualSub、隐藏网站自带的字幕、原文字幕的语言、是否使用节目自带的翻译、外观和你自己的外观、译文颜色、大小、间距、位置、行序与排列，以及时间。每个网站只保存它单独保留的值，其余都跟随 **所有网站**。你的语言、翻译服务、查词、AI 解释和密钥在所有网站上都相同。

打开高级选项后，在设置页顶部的栏中选择一个网站。之后的更改会带有“仅限 Netflix”标签（在“样式”中，相应的行上会出现一个圆点），点击 **改用“所有网站”** 即可去掉该网站自己的值。“网站”部分列出每个网站单独保留的设置，并可一键移除。

弹出窗口修改的是当前网站实际使用的值：网站有自己的值时修改它自己的值，否则修改共享的值。其中的开关始终只作用于该网站。

## API 密钥

API 密钥只保存在这台电脑上：不会同步，也不会写入备份文件。密钥只会发送到输入它时所用的地址。地址换到其他主机时（无论是在这台电脑上、在同步的其他电脑上，还是通过载入备份），DualSub 都会把该密钥视为未填写，直到你为新地址输入密钥。
