# 配置设置

## 弹出设置（快速）

- 启用/禁用双语字幕
- 语言：翻译语言默认跟随浏览器的语言。上行字幕默认为「自动」，跟随视频中所说的语言，在播放器里切换音轨时也会跟随；也可以固定为某一种语言，用于每个视频都学习同一种语言。视频本身就是翻译语言时，DualSub 只显示一行。
- 布局（上下/左右）、外观与时间偏移
- 字幕样式：「跟随平台」按你的 Netflix / Disney+ 账户字幕外观设置绘制；「自定义」以 DualSub 自身的外观为起点，在设置页编辑。译文行的颜色是独立设置，两种样式都使用。字体大小是相对基准大小的缩放倍数，基准随视频高度变化。

## 按网站设置

Netflix 与 Disney+ 可以各自保留以下设置：是否显示双语字幕、隐藏网站自带字幕、上行字幕的语言、官方翻译、字幕样式与自定义外观、译文颜色、字号、行距、位置、行序与排列，以及时间偏移。每个网站只保存与「所有网站」不同的部分，其余都跟随所有网站的设置。翻译语言、翻译服务、单词解释与 API 密钥在所有网站上相同。

弹出窗口修改的是当前网站实际使用的值：网站有自己的值时修改它自己的值，否则修改共享的值。

## 高级选项

- 界面语言（EN、ES、JA、KO、ZH-CN、ZH-TW）
- 隐藏官方字幕
- 日志级别
- 服务商 API 密钥与请求延迟调优
- AI 上下文设置（服务商、模型、缓存、速率限制、超时）

## 示例

语言学习：

- 服务商：Microsoft 翻译（免密钥，尽力而为）
- 布局：上下（原文优先）
- AI 上下文：OpenAI GPT-5.6 Luna（文化/历史/语言）

性能优先：

- 请求延迟：100ms
- 服务商：Google 翻译
- AI 上下文：Gemini 3.5 Flash；启用上下文缓存

高级用户：

- 服务商：OpenAI 兼容
- AI 上下文：OpenAI GPT-5.6 Luna
- 速率限制：60 次/分钟；缓存 TTL：1 小时；调试日志：启用
