# 查词与 AI 解释

点一下字幕里的单词，就能看到它的意思，无需任何设置：视频会暂停，侧边栏显示这个词所在的字幕、它的翻译和词典释义。在字幕里或面板中的那一行里多点几个词，可以查整个短语；点一下视频即可继续观看。

## 释义来自哪里

- 翻译：设置页“翻译”部分选择的翻译服务
- 词典：Google 词典；Google 没有收录时改用维基词典（Wiktionary），其英文释义由你的翻译服务译出。每条释义都会注明来源。

要让字幕单词不能点击，在设置页的 **释义** 部分关闭 **点击单词时查词**。

## 用 AI 解释

面板中的 **用 AI 解释** 会请 AI 服务说明这些词在这一行里的用法：在这里是什么意思，口语还是正式。**解释哪些内容** 可以加上例句和类似的说法、背后的文化，以及历史和来历。

它通过你自己的密钥工作：

- OpenAI GPT：GPT-5.6 Luna（推荐）、GPT-5.6 Terra、GPT-5.6
- Google Gemini：Gemini 3.5 Flash（推荐）、Gemini 2.5 Flash、Gemini 2.5 Pro

没有密钥时，这个按钮会在面板中打开三个步骤：选择服务，到它的页面获取密钥，粘贴后点击 **检查并解释**。“释义”部分也有同样的步骤。放入密钥后，这些步骤会收起为服务的名称；点击 **更换密钥** 可以重新打开。

打开高级选项后，“释义”部分还可以设置模型、各项限制（默认每分钟 60 次请求，回答记住一小时），以及自定义 OpenAI 兼容端点的地址。通过“允许访问 API 主机”授予 Chrome 对该协议和主机的权限；权限覆盖所有路径和端口。

## 阅读时

**我看解释的时候** 决定点击单词时是否打开面板、是否暂停视频。**面板颜色** 可以让面板显示为浅色、深色，或跟随电脑设置。

## 隐私

- 点击的单词会发送给你的翻译服务和 Google 词典；Google 没有收录时还会发送给维基词典
- “用 AI 解释”只在你点击时，把这些词和它们所在的字幕行发送给你的 AI 服务
- 回答只保存在有界的内存缓存中，DualSub 不会保存

参见：`src/background/lookup/`（词典），以及 `src/background/aicontext/`（AI 服务商、提示词与回答结构）。
