# 单词解释（AI 上下文分析）

为选中的字幕文本提供文化、历史与语言层面的解释。

## 支持的服务商

- OpenAI GPT：GPT-5.6 Luna（推荐）、GPT-5.6 Terra、GPT-5.6
- Google Gemini：Gemini 3.5 Flash（推荐）、Gemini 2.5 Flash、Gemini 2.5 Pro

## 速率限制与缓存

- 默认：60 次/分钟，强制 1 秒延迟
- 缓存：默认 TTL 1 小时，定期清理 + LRU

## 设置

在设置页中打开 **单词解释**，按其中的三个步骤操作：

1. 选择服务（Gemini 或 OpenAI）
2. 打开该服务的密钥页面并创建密钥
3. 粘贴密钥后点击 **打开**；放入密钥之前，开关保持关闭

打开单词解释后，这些步骤会收起为服务的名称；点击 **更换密钥** 可以重新打开。

打开高级选项后，同一部分还可以设置模型、各项限制，以及自定义 OpenAI 兼容端点的地址。通过“允许 API 主机”授予 Chrome 对该协议和主机的权限；权限覆盖所有路径和端口。

## 使用方法

- 点击字幕单词组成短语，并在 Chrome 侧边栏中查看分析
- 可启用文化、历史、语言分析的任意精确组合
- 可以选择点击单词时是否打开面板，以及阅读时是否暂停视频

## 隐私

- 所选文本、语言信息和有限的周边字幕上下文会发送给已配置的 AI 服务商
- 启用缓存时结果只保存在有界的内存缓存中，DualSub 不会永久保存

参见：`src/background/aicontext/`（服务商、提示词与响应模式）。
