# 查词与 AI 解释

点一下字幕里的单词，就能看到它的意思，无需任何设置。视频会暂停，侧边栏显示这一行字幕、这个词的翻译和词典释义。要查整个短语，就在字幕里或面板中的那一行里多点几个词；在面板中点一下已选的词即可去掉它。点一下视频即可继续观看。

## 释义来自哪里

- 翻译来自你的[翻译服务](providers.md)。
- 词典释义来自 Google 词典；Google 没有收录或没有回应时，改用维基词典（Wiktionary）。维基词典的释义是英文的，由你的翻译服务译出。每条释义都会注明来源。

要让字幕里的词不能点击，在设置页的 **释义** 部分关闭 **点击单词时查词**。

## 用 AI 解释

面板中的 **用 AI 解释** 会请 AI 服务说明这些词在这一行里的用法：在这里是什么意思，口语还是正式。“释义”部分的 **解释哪些内容** 可以加上更多内容，默认全部开启：

- **意思和用法**：例句和类似的说法
- **背后的文化**
- **历史和来历**

它需要你自己的以下任一服务的密钥：

- OpenAI：GPT-5.6 Luna（默认）、GPT-5.6 Terra 或 GPT-5.6
- Google Gemini：Gemini 3.5 Flash（默认）、Gemini 2.5 Flash 或 Gemini 2.5 Pro

没有密钥时，这个按钮会在面板中打开三个步骤：选择服务，到它的页面获取密钥，粘贴后点击 **检查并解释**。“释义”部分也有同样的步骤。放入密钥后，这些步骤会收起为服务的名称，点击 **更换密钥** 可以重新打开。

打开高级选项后，“释义”部分还可以设置模型（OpenAI 可填写任意模型名称）、各项限制（默认每分钟 60 次请求，回答记住一小时），以及其他 OpenAI 兼容服务器的地址。使用这样的地址时，点击 **允许访问 API 主机**，让 DualSub 可以连接它；权限覆盖该主机的所有路径和端口。

## 阅读时

**我看解释的时候** 决定点击单词时是否打开面板、是否暂停视频。**面板颜色** 可以让面板显示为浅色、深色，或跟随电脑设置。

## 隐私

- 你点击的词会发送给你的翻译服务和 Google 词典；Google 没有收录或没有回应时，还会发送给维基词典。
- **用 AI 解释** 只在你点击时，把这些词和它们所在的字幕行发送给你的 AI 服务。
- 回答只在内存中保留有限的时间，DualSub 不会保存。

DualSub 发送的全部内容及去向，见[隐私政策](../../PRIVACY_POLICY.md)（英文）。

## 常见问题

- **字幕里的词不能点击**：在“释义”部分开启 **点击单词时查词**。
- **“这个词单独查不到”**：点一下它前后的词，查整个短语。
- **“这个密钥用不了”**：检查密钥或重新获取一个，然后点击 **检查并解释**。
- **“AI 服务没有回应”**：点击 **重试**。打开高级选项后，检查“释义”部分的 **每分钟最多请求次数**。
